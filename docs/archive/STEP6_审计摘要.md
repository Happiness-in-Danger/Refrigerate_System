### 2.3 参数持久化 ✅

**实现**: `Board/params_store.py` (181 行完整实现)  
**机制**:
- 开机加载: `load_config()` ← config.json
- 写入触发: Modbus 写后 `mark_dirty()` → 30s 防抖
- 立即保存: SAFE_STOP 入口 `save_if_dirty()`
- 原子写: tmp + rename
- checksum 校验: 16-bit 累加和
- 损坏回退: 使用 state.py 默认值
