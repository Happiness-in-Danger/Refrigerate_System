## 0. 地址约定

| 概念 | 定义 |
|---|---|
| **显示地址** | 触摸屏/上位机按 Modbus 数据模型显示的 1 基地址（如 `4x1`、`3x1`、`0x1`、`1x1`） |
| **报文地址** | 报文 PDU 中的 0 基偏移（标准 Modbus）；**= 代码索引**，无额外偏移 |
| **代码索引** | 固件内部数组下标（0 基） |

换算公式：显示地址 = 代码索引 + 1。报文地址 = 代码索引（标准 Modbus，屏发 0 基）。

功能码：

| 功能码 | 地址区 | 数据类型 | 读写 | 用途 |
|---|---|---|---|---|
| 01 | 0x | 位 | 只读 | 读线圈 |
| 02 | 1x | 位 | 只读 | 读离散量输入 |
| 03 | 4x | 字 | 只读 | 读保持寄存器 |
| 04 | 3x | 字 | 只读 | 读输入寄存器 |
| 05 | 0x | 位 | 写单个 | 写单个线圈 |
| 06 | 4x | 字 | 写单个 | 写单个保持寄存器 |
| 0F | 0x | 位 | 写多个 | 写多个线圈 |
| 10 | 4x | 字 | 写多个 | 写多个保持寄存器 |

## 1. 写入权限总览

> **样机范围**：当前样机为风冷式直膨制冷，无水/载冷剂回路。Coil 0x6 `FLOW_ENABLE` 与 1x16 `FLOW_FAULT` 为后续带水回路版本预留；当前 `di_flow` 是软件占位，不是实体 DI。当前样机保持 `FLOW_ENABLE=0`。

| 区域 | 读 | 写 | 说明 |
|---|---|---|---|
| Coils 0x1-0x8 | ✅ | ✅ | 0x7 为复位脉冲（回读恒 0） |
| Discrete 1x1-1x16 / 1x100-1x105 | ✅ | ❌ | 只读 |
| Holding 4x1-4x223 | ✅ | ✅ | 稀疏地址，未定义地址写入返回 `0x02` |
| Input 3x1-3x223 | ✅ | ❌ | 只读 |

- 越界写入 → `0x03`；违反分级阈值一致性 → `0x03`。
- **掉电保存**：配置类参数（PID/阈值/延时槽/启动/转速环/防短循环）修改后 30s 防抖落盘；
  线圈 `0x3-0x5/0x8` 同样持久化；`0x1` 系统使能、`0x2` 手动、`0x7` 复位脉冲与 4x220-223 手动指令不保存。
